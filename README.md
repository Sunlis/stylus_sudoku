# Stylus Sudoku

A sudoku PWA built for e-ink devices and stylus input. Supports handwriting recognition to enter digits, freehand annotation layers, and hint assistance.

Live: https://sunlis.github.io/stylus_sudoku

## Commands

```bash
npm run dev      # start dev server
npm run build    # production build
npm run preview  # preview production build locally
npm run test     # run tests
npm run deploy   # build and deploy to GitHub Pages
```
